# Sendflow

Projeto SaaS de broadcast com React, TypeScript, Vite, Firebase Auth, Firestore, Cloud Functions e Firebase Hosting.

## Estrutura

- `web`: frontend React.
- `functions`: Cloud Functions.
- `firestore.rules`: regras de seguranca do Firestore.
- `firebase.json`: configuracao de Hosting, Functions e Firestore.

## Scripts

```bash
pnpm install
pnpm dev
pnpm build
pnpm lint
```
